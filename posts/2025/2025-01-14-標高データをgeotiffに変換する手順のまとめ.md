### 標高データをGeoTIFFに変換する手順のまとめ

こんにちは！3年の佐藤愛妃です！

今回は、XML形式の標高データをGeoTIFF形式に変換するプロジェクトについてご紹介します。この作業は、地形データの可視化や分析を効率化するための基本的なステップです。サンプルデータとして、神奈川県相模原市-東京都町田市の境目付近のデータセットを使用しました。

言語はPython、作業環境はGoogle Caloboratryの無料枠です。GDAL使用予定でしたが、途中でエラーが出たので、ファイル解析に工程変更して作業を進めています…

GitHubのリポジトリにまとめてあります。

[https://github.com/akidinosaurs/ElevationToGeoTIFF](https://github.com/akidinosaurs/ElevationToGeoTIFF)

#### 概要

今週は、標高データを以下の手順で処理しました：

1. **標高データの準備**: 国土地理院からGML形式の標高データをダウンロードし、Google Driveにアップロード。

1. **XML解析**: ダウンロードしたデータをPythonで解析し、標高値を抽出。

1. **データ変換**: 抽出した標高値を行列形式に変換。

1. **GeoTIFF生成**: rasterioを使用してGeoTIFF形式のファイルを生成。

1. **結果の可視化**: 生成したGeoTIFFファイルをPythonで可視化。

1. **データ保存**: 標高データを表形式に変換してCSVファイルに保存。

#### 使用したツールと注意点

- **使用ツール**: Python（rasterio、numpy、matplotlib、pandasなど）

- **環境設定**: Google Colaboratoryを使用して作業を進めました。無料枠のタイムアウトに注意しながら進めました。

- **注意点**:

- 欠損値（-9999など）に適切に対処すること。

- GeoTIFFが正しく出力されない場合はデータ範囲や設定値を確認する。

2. 標高データの準備

国土地理院のサイトからデータをダウンロードし、Google Driveにアップロード。マウント時にエラーが発生することがあったため、再接続を試みることで解決しました。

3. XMLファイルの解析

以下のコードで標高データを抽出しました：

```javascript
import xml.etree.ElementTree as ET
```

```ini
# XMLファイルを読み込む
input_file = "/content/drive/My Drive/Colab Notebooks/Sonification/challenge1/FG-GML.xml"
tree = ET.parse(input_file)
root = tree.getroot()
```

```
# 標高データを収集
elevation_data = []
for elem in root.iter():
    if "tupleList" in elem.tag:
        raw_data = elem.text.strip()
        for line in raw_data.splitlines():
            parts = line.split(',')
            if len(parts) == 2:
                elevation_data.append(float(parts[1]))
```

4. 標高データを行列形式に変換

```javascript
import numpy as np
```

```sql
rows, cols = 225, 150
elevation_matrix = np.array(elevation_data).reshape((rows, cols))
```

5. GeoTIFF形式に変換

rasterioを用いてGeoTIFF形式に変換しました：

```javascript
import rasterio
from rasterio.transform import from_origin
```

```
output_tiff = "/content/drive/My Drive/Colab Notebooks/Sonification/challenge1/elevation.tif"
transform = from_origin(139.375, 35.508333333, 0.0001, 0.0001)
```

```python
with rasterio.open(
    output_tiff,
    'w',
    driver='GTiff',
    height=rows,
    width=cols,
    count=1,
    dtype=str(elevation_matrix.dtype),
    crs='EPSG:4326',
    transform=transform
) as dst:
    dst.write(elevation_matrix, 1)
```

6. 作成したGeoTIFFを確認

Pythonで可視化しました：

```javascript
import matplotlib.pyplot as plt
```

```kotlin
with rasterio.open(output_tiff) as src:
    data = src.read(1)
```

```
plt.figure(figsize=(10, 8))
plt.imshow(data, cmap='terrain')
plt.colorbar(label='Elevation (m)')

```
